# nathanroark.dev

My developer site: [nathanroark.dev](https://nathanroark.dev)

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com)

## Run in dev mode

```sh
bun i
bun run dev
```

## Lint

```sh
bun run lint
```

## Format

```sh
bun run format
```

### Misc

Page content (projects, education, skills, etc...) is in `src/config/content.ts`
